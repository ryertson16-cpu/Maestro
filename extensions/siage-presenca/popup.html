Planilha de aulas (CSV novo do Maestro, com Id Maestro)

Pode escolher um CSV com várias turmas ou vários arquivos de uma vez. A extensão abre cada turma no SIAGE sozinha. Depois de cada aula, atualiza o livro-razão.

Registrar só as aulas de até
"Até" começa em hoje, para não lançar aulas que ainda não aconteceram.
Senha do SIAGE (para confirmar cada registro): Fica só na memória do Chrome até terminar; nunca é gravada em disco.
Notas do SIAGE (JSON ou planilha das 3 unidades)

Use o JSON ou a planilha das 3 unidades (Aluno, 1ª unidade…). Não use o CSV de aula (Data, Tempos). Abra a tela de notas da turma no SIAGE. Digite a senha no campo acima.

O professor ainda pode alterar no SIAGE. O SIAGE não deixa mais mudar.
